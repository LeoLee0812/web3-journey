> **一句话结论：** Web3 术语纷繁，但掌握按层级分类的 60 个核心词汇，足以读懂 80% 的技术讨论和社群对话。

## 为什么 Web3 术语这么难懂

Web3 融合了密码学、分布式系统、金融多个专业，每个领域有自己的术语。而且这个领域很年轻，新概念不断涌现。但好消息是：**核心术语集中在 60 个左右。** 掌握这 60 个就能理解大多数对话。这一节帮你快速建立术语框架。

## 术语的四层金字塔

Web3 术语按逻辑可以分成四个层级，从下往上依次是更高层的抽象：

### 第一层：基础单位与费用

最底层的词汇涉及单位换算和成本计算。这是最容易出错的地方。

| 术语 | 缩写 | 中文 | 说明 | 示例 |
|-----|------|------|------|------|
| Wei | - | 最小单位 | 1 ETH = 10^18 Wei | 转账 0.001 ETH = 10^15 Wei |
| Gwei | - | 十亿分之一以太 | 1 Gwei = 10^9 Wei；Gas 价格用 Gwei 表示 | Gas price 25 Gwei |
| Gas | - | 燃料费 | 每次链上操作消耗的计算资源单位 | 转账需要 21,000 Gas |
| Base Fee | - | 基础费 | 以太坊 EIP-1559 后的最低 Gas 价格，动态调整 | 当前 base fee 15 Gwei |
| Priority Fee | - | 优先费 | 额外支付给验证者的费用，用来加快交易 | 支付 2 Gwei 优先费 |
| Transaction Hash | Tx Hash | 交易哈希 | 每笔交易的唯一标识，可在区块浏览器查询 | 0x3f...c2a |
| Block | - | 区块 | 打包一批交易的账本单元，按顺序连接成链 | 区块高度 2500 万 |
| Confirmation | - | 确认数 | 某笔交易之后新增的区块数，数值越大越难篡改 | 12 个确认视为最终 |
| Testnet | - | 测试网 | 模拟主网环境但不涉及真实资产的测试链 | Sepolia、Holesky |
| Mainnet | - | 主网 | 正式上线、处理真实资产交易的区块链 | 以太坊主网 |
| Faucet | - | 水龙头 | 免费发放测试网代币供开发调试使用的工具 | Sepolia Faucet |
| EIP | Ethereum Improvement Proposal | 以太坊改进提案 | 社区提交并讨论以太坊协议升级的标准文件 | EIP-1559、EIP-4844 |

**最常见的混淆：** 新手经常把 Gas 和 Gwei 搞混，或者以为 Gas 就是用 ETH 计价的。实际上，Gas 费用 = Gas 用量 × Gas 价格(Gwei)，转换回 ETH 时才除以 10^9。

### 第二层：网络参与者与账户

这一层涉及参与链的各类角色和账户概念：

| 术语 | 缩写 | 中文 | 说明 |
|-----|------|------|------|
| Node | - | 节点 | 运行区块链完整软件的计算机 |
| Validator | - | 验证者 | PoS 网络中参与共识、产生区块的节点运营者 |
| Account | - | 账户 | 区块链上的身份，由公钥生成 |
| Address | - | 地址 | 账户的公开标识符，类似银行卡号 |
| Private Key | - | 私钥 | 64 个十六进制字符，用来签署交易和转移资产 |
| Public Key | - | 公钥 | 从私钥推导出来，公开且无法反推私钥 |
| Seed Phrase | - | 种子短语 | 12 或 24 个单词，可用来恢复钱包 |
| Staking | - | 质押 | 锁定加密资产参与 PoS 共识，获得收益 |
| Nonce | - | 交易序号 | 账户的交易计数器，每笔交易递增 1 |
| Hot Wallet | - | 热钱包 | 联网状态下随时可用的钱包，便捷但风险较高 |
| Cold Wallet | - | 冷钱包 | 私钥离线存储的钱包（硬件钱包为主），安全性更高 |
| Multisig | - | 多签钱包 | 需要多个私钥共同签名才能完成转账的钱包 |
| Custody | - | 托管 | 私钥由第三方（如交易所）代为保管，用户不直接掌握 |
| Airdrop | - | 空投 | 项目方免费向符合条件的地址发放代币的营销方式 |
| KYC | Know Your Customer | 身份验证 | 交易所要求用户提交身份信息以符合监管要求 |
| Whale | - | 巨鲸 | 持有大量某种资产、交易能显著影响市场价格的地址 |

### 第三层：智能合约与应用

这一层是 Web3 最核心的创新——可编程的链上逻辑：

| 术语 | 缩写 | 中文 | 说明 |
|-----|------|------|------|
| Smart Contract | - | 智能合约 | 部署在链上、自动执行的程序代码 |
| Contract Address | - | 合约地址 | 智能合约在链上的地址，与普通账户不同 |
| DApp | - | 去中心化应用 | 基于智能合约的应用，用户通过钱包与之交互 |
| ABI | Application Binary Interface | 应用二进制接口 | 描述合约有哪些函数、参数、返回值 |
| Function Call | - | 函数调用 | 触发智能合约某个特定功能的交易 |
| Approval | - | 授权 | 给某个合约转账权限，通常分两步执行 |
| Revoke | - | 撤销授权 | 取消之前给某合约的转账权限 |
| Self-custody | - | 自托管 | 用户自己保管私钥，而不是交给第三方 |
| Oracle | - | 预言机 | 把链下真实世界数据（如价格）传给智能合约的服务 |
| AMM | Automated Market Maker | 自动做市商 | 用算法公式而非订单簿撮合交易的机制 |
| Liquidity Pool | - | 流动性池 | 用户存入资产供他人交易，换取手续费分成 |
| Slippage | - | 滑点 | 下单价格与实际成交价格之间的偏差 |
| Mint | - | 铸造 | 创建新的代币或 NFT 并写入区块链 |
| Burn | - | 销毁 | 把代币永久发送到无法使用的地址，减少流通量 |
| Governance Token | - | 治理代币 | 持有者可对协议参数、升级方向进行投票的代币 |
| DAO | Decentralized Autonomous Organization | 去中心化自治组织 | 由代币持有者通过链上投票共同决策的组织形式 |

### 第四层：扩容与跨链

这一层解决的是可扩展性问题——如何让链处理更多交易、更低成本：

| 术语 | 缩写 | 中文 | 说明 |
|-----|------|------|------|
| Layer 1 | L1 | 第一层（主链） | 比特币、以太坊这类基础区块链 |
| Layer 2 | L2 | 第二层 | 建立在 L1 之上、继承 L1 安全性的扩容方案 |
| Rollup | - | 汇总 | 将多笔交易打包后提交到 L1 的扩容方式 |
| Optimistic Rollup | - | 乐观汇总 | 默认交易有效，有问题才触发欺诈证明；代表：Arbitrum、Optimism |
| ZK Rollup | - | 零知识汇总 | 用零知识证明即时证明交易有效；代表：zkSync、Starknet |
| Bridge | - | 跨链桥 | 连接两条不同区块链的协议，可互转资产 |
| TVL | Total Value Locked | 锁定总价值 | 某个协议中用户存入的资产总额 |
| Blob | - | 数据块 | 以太坊 EIP-4844(2024 年 Dencun 升级)引入的廉价数据存储方式 |
| Sidechain | - | 侧链 | 与主链并行运行、通过桥接交互资产的独立链 |
| Sharding | - | 分片 | 把网络拆成多个并行处理片区以提升整体吞吐量 |
| Data Availability | DA | 数据可用性 | 保证交易数据确实被公开发布、可供任何人验证 |
| Finality | - | 最终性 | 交易被网络确认后不可逆转的状态 |
| Interoperability | - | 互操作性 | 不同区块链之间传递资产和信息的能力 |
| Cross-chain | - | 跨链 | 泛指资产或消息在不同区块链间流转的行为 |

## 🧪 真实场景：在 Arbitrum 上交换代币

你在 Arbitrum(L2)通过 Uniswap 用 1000 USDC 换 ETH，过程分两步：

**第一步：授权(Approval)** — 调用 USDC 代币合约的 approve 函数，Gas fee 约 2 美元

**第二步：交换(Swap)** — Uniswap 合约从流动性池提取 ETH 给你，Gas fee 约 0.5 美元（L2 便宜 100-1000 倍）

交易完成后得到一个 Tx Hash，在 Arbiscan 查询。7 天内没被欺诈证明挑战，就在 L1 最终确认。这个过程涉及：L2、Approval、Swap、Gas、Tx Hash、AMM、流动性……都是上面表格里的术语。

## ⚠️ 常见坑与误区

1. **Gas 和 Gwei 混淆**
   - 费用 = Gas 用量 × Gas 价格(Gwei)，转换回 ETH 需除以 10^9

2. **地址和私钥混淆**
   - 地址公开如银行卡号，私钥绝密如密码，永远不要分享私钥

3. **「授权」与「转账」混淆**
   - 授权(Approve)只给权限不转账，实际转账需第二笔交易

4. **跨链地址混淆**
   - Bitcoin 和 Ethereum 地址格式完全不同，转错无法恢复

## 本节要点

- Web3 术语按层级分为：基础单位 → 网络参与者 → 智能合约 → 扩容
- Gas 费 = Gas 用量 × Gas 价格(Gwei)，转换回 ETH 需除以 10^9
- 地址公开如账号，私钥绝密如密码，永不混淆亦不外泄
- Layer 2 通过 Rollup 继承 L1 安全性，交易成本降低 100-1000 倍
- 「授权(Approve)」只给权限不转账，实际转账需第二笔交易
