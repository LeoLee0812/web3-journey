## 这是什么

一套**为零基础中文读者**写的 Web3 系统知识库。不是名词罗列，也不是喊单频道：每一节都从「你现在能理解的东西」出发，讲清一个概念的**原理、边界和实操**，再告诉你它在真实市场里怎么用、怎么亏钱。

<CardGrid stagger>
  <Card title="从零起步" icon="rocket">
    第 1–3 章不假设任何背景知识。哈希、私钥、共识这些词，用班级记账本和快递柜就能讲明白。
  </Card>
  <Card title="能动手" icon="setting">
    第 4–7 章每节都带可跟做的操作流程：建钱包、读区块、发交易、查授权、做一笔 Swap。
  </Card>
  <Card title="能研究" icon="magnifier">
    第 8–11 章给的是可复用的工作流：项目六维打分表、链上资金追踪、协议评估十二步、空投成本核算表。
  </Card>
  <Card title="能求职" icon="star">
    第 12–13 章面向真实岗位：安全风控手册、行业岗位地图、社区增长打法、AI 自动化提效、作品集与面试题。
  </Card>
</CardGrid>
