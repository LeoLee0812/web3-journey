## 先说清楚：这本书想帮你做到什么

读完之后，你应该能做到下面五件事中的任意一件——而不是「听说过很多名词」：

1. 向一个完全不懂的人，用三分钟讲清楚区块链为什么改不了；
2. 独立创建并安全管理一个自托管钱包，看懂每一笔交易的每一栏；
3. 打开一个陌生项目的合约地址，判断它有没有明显的跑路准备；
4. 用一套固定流程，产出一份结构完整的项目研究报告；
5. 看懂 Web3 行业的岗位地图，知道自己缺哪块能力、怎么补。

<Aside type="caution" title="不会帮你做到的事">
本书**不推荐任何具体币种、协议或平台去投资**，不预测价格，也不提供「稳赚方法」。文中出现的所有项目都只作为机制讲解的例子。
</Aside>

## 阅读约定

<Steps>

1. **每节开头有「一句话结论」**：赶时间的话，只读这一行 + 末尾的「本节要点」，也能建立骨架。

2. **带 🧪 的段落是可跟做的实操**：需要你打开浏览器或钱包。第一次做建议用**测试网**或**极小金额**。

3. **带 ⚠️ 的段落是真金白银的坑**：这些通常来自真实事故，请不要跳过。

4. **术语首次出现时给中英文对照**：例如「无常损失（Impermanent Loss，IL）」。全书术语汇总见[第 1 章第 3 节](/01-what-is-web3/03-glossary-map/)。

5. **所有数字都标注了口径与时间**：加密行业变化极快，看到具体数值时请注意它的时间戳，并自行核实最新情况。

</Steps>
