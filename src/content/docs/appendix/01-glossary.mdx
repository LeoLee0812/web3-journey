## 最容易混淆的 8 组概念

| 概念 A | 概念 B | 核心区别 |
|---|---|---|
| Layer 1（[2.6](/02-blockchain-basics/06-trilemma/)） | Layer 2（[9.1](/09-layer2-multichain/01-why-scaling/)） | L1 是独立结算的基础链，安全和最终性都由自己承担；L2 建在 L1 之上处理交易，定期向 L1 提交证明，安全性来自 L1 |
| APR（[8.3](/08-defi/03-yield-farming/)） | APY（[8.3](/08-defi/03-yield-farming/)） | APR 是不计复利的年化数字，看着更高；APY 计入复投频率，才是更贴近真实到手收益的口径 |
| 代币（[6.1](/06-tokens-nft/01-token-standards/)） | 币（原生代币 / Coin） | 币指某条链自己的原生资产（如 ETH、BTC），用来付 Gas；代币是在别人的链上用合约标准发行的资产，本身不能直接付 Gas |
| 热钱包（[4.1](/04-wallets/01-wallet-types/)） | 冷钱包（[4.1](/04-wallets/01-wallet-types/)） | 热钱包私钥在联网设备上，操作快但暴露面大；冷钱包私钥从不接触网络，安全性高但每次交易流程更繁琐 |
| 无常损失（[7.4](/07-exchanges-trading/04-lp-and-il/)） | 普通亏损 | 无常损失特指做市商因池内两种资产价格比例变动、相对单纯持有产生的账面差额，撤出后才会"坐实"；普通亏损是资产本身价格下跌造成的直接损失 |
| 私钥（[3.2](/03-cryptography/02-private-public-key/)） | 助记词（[3.3](/03-cryptography/03-mnemonic-bip39/)） | 私钥对应单个地址，是最终的签名密钥；助记词是一整个种子，能通过 HD 派生生成无数个私钥和地址 |
| Rollup（[9.2](/09-layer2-multichain/02-rollup-optimistic/)） | 侧链（[9.4](/09-layer2-multichain/04-l2-landscape/)） | Rollup 把交易数据和证明提交回 L1，安全性继承主链；侧链是独立运行的另一条链，靠自己的验证者集合保障安全，风险与主链无关 |
| 质押（[2.5](/02-blockchain-basics/05-consensus-pos/)） | 挖矿（[2.4](/02-blockchain-basics/04-consensus-pow/)） | 质押是 PoS 机制下锁定资本参与共识，作恶被扣本金；挖矿是 PoW 机制下用算力竞争记账权，成本是电力和硬件而非资本冻结 |
