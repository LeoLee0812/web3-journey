> **一句話結論：** Web3 術語紛繁，但掌握按層級分類的 60 個核心詞彙，足以讀懂 80% 的技術討論和社群對話。

## 為什麼 Web3 術語這麼難懂

Web3 融合了密碼學、分散式系統、金融多個專業，每個領域有自己的術語。而且這個領域很年輕，新概念不斷湧現。但好訊息是：**核心術語集中在 60 個左右。** 掌握這 60 個就能理解大多數對話。這一節幫你快速建立術語框架。

## 術語的四層金字塔

Web3 術語按邏輯可以分成四個層級，從下往上依次是更高層的抽象：

### 第一層：基礎單位與費用

最底層的詞彙涉及單位換算和成本計算。這是最容易出錯的地方。

| 術語 | 縮寫 | 中文 | 說明 | 示例 |
|-----|------|------|------|------|
| Wei | - | 最小單位 | 1 ETH = 10^18 Wei | 轉帳 0.001 ETH = 10^15 Wei |
| Gwei | - | 十億分之一以太 | 1 Gwei = 10^9 Wei；Gas 價格用 Gwei 表示 | Gas price 25 Gwei |
| Gas | - | 燃料費 | 每次鏈上操作消耗的計算資源單位 | 轉帳需要 21,000 Gas |
| Base Fee | - | 基礎費 | 以太坊 EIP-1559 後的最低 Gas 價格，動態調整 | 當前 base fee 15 Gwei |
| Priority Fee | - | 優先費 | 額外支付給驗證者的費用，用來加快交易 | 支付 2 Gwei 優先費 |
| Transaction Hash | Tx Hash | 交易雜湊 | 每筆交易的唯一標識，可在區塊瀏覽器查詢 | 0x3f...c2a |
| Block | - | 區塊 | 打包一批交易的帳本單元，按順序連結成鏈 | 區塊高度 2500 萬 |
| Confirmation | - | 確認數 | 某筆交易之後新增的區塊數，數值越大越難篡改 | 12 個確認視為最終 |
| Testnet | - | 測試網 | 模擬主網環境但不涉及真實資產的測試鏈 | Sepolia、Holesky |
| Mainnet | - | 主網 | 正式上線、處理真實資產交易的區塊鏈 | 以太坊主網 |
| Faucet | - | 水龍頭 | 免費發放測試網代幣供開發除錯使用的工具 | Sepolia Faucet |
| EIP | Ethereum Improvement Proposal | 以太坊改進提案 | 社群提交併討論以太坊協議升級的標準檔案 | EIP-1559、EIP-4844 |

**最常見的混淆：** 新手經常把 Gas 和 Gwei 搞混，或者以為 Gas 就是用 ETH 計價的。實際上，Gas 費用 = Gas 用量 × Gas 價格(Gwei)，轉換回 ETH 時才除以 10^9。

### 第二層：網路參與者與帳戶

這一層涉及參與鏈的各類角色和帳戶概念：

| 術語 | 縮寫 | 中文 | 說明 |
|-----|------|------|------|
| Node | - | 節點 | 執行區塊鏈完整軟體的計算機 |
| Validator | - | 驗證者 | PoS 網路中參與共識、產生區塊的節點運營者 |
| Account | - | 帳戶 | 區塊鏈上的身份，由公鑰生成 |
| Address | - | 地址 | 帳戶的公開識別符號，類似銀行卡號 |
| Private Key | - | 私鑰 | 64 個十六進位制字元，用來簽署交易和轉移資產 |
| Public Key | - | 公鑰 | 從私鑰推匯出來，公開且無法反推私鑰 |
| Seed Phrase | - | 種子短語 | 12 或 24 個單詞，可用來恢復錢包 |
| Staking | - | 質押 | 鎖定加密資產參與 PoS 共識，獲得收益 |
| Nonce | - | 交易序號 | 帳戶的交易計數器，每筆交易遞增 1 |
| Hot Wallet | - | 熱錢包 | 聯網狀態下隨時可用的錢包，便捷但風險較高 |
| Cold Wallet | - | 冷錢包 | 私鑰離線儲存的錢包（硬體錢包為主），安全性更高 |
| Multisig | - | 多籤錢包 | 需要多個私鑰共同簽名才能完成轉帳的錢包 |
| Custody | - | 託管 | 私鑰由第三方（如交易所）代為保管，使用者不直接掌握 |
| Airdrop | - | 空投 | 專案方免費向符合條件的地址發放代幣的營銷方式 |
| KYC | Know Your Customer | 身份驗證 | 交易所要求使用者提交身份資訊以符合監管要求 |
| Whale | - | 巨鯨 | 持有大量某種資產、交易能顯著影響市場價格的地址 |

### 第三層：智能合約與應用

這一層是 Web3 最核心的創新——可程式設計的鏈上邏輯：

| 術語 | 縮寫 | 中文 | 說明 |
|-----|------|------|------|
| Smart Contract | - | 智能合約 | 部署在鏈上、自動執行的程式程式碼 |
| Contract Address | - | 合約地址 | 智能合約在鏈上的地址，與普通帳戶不同 |
| DApp | - | 去中心化應用 | 基於智能合約的應用，使用者通過錢包與之互動 |
| ABI | Application Binary Interface | 應用二進位制介面 | 描述合約有哪些函式、引數、返回值 |
| Function Call | - | 函式呼叫 | 觸發智能合約某個特定功能的交易 |
| Approval | - | 授權 | 給某個合約轉帳許可權，通常分兩步執行 |
| Revoke | - | 撤銷授權 | 取消之前給某合約的轉帳許可權 |
| Self-custody | - | 自託管 | 使用者自己保管私鑰，而不是交給第三方 |
| Oracle | - | 預言機 | 把鏈下真實世界資料（如價格）傳給智能合約的服務 |
| AMM | Automated Market Maker | 自動做市商 | 用演算法公式而非訂單簿撮合交易的機制 |
| Liquidity Pool | - | 流動性池 | 使用者存入資產供他人交易，換取手續費分成 |
| Slippage | - | 滑點 | 下單價格與實際成交價格之間的偏差 |
| Mint | - | 鑄造 | 建立新的代幣或 NFT 並寫入區塊鏈 |
| Burn | - | 銷燬 | 把代幣永久傳送到無法使用的地址，減少流通量 |
| Governance Token | - | 治理代幣 | 持有者可對協議引數、升級方向進行投票的代幣 |
| DAO | Decentralized Autonomous Organization | 去中心化自治組織 | 由代幣持有者通過鏈上投票共同決策的組織形式 |

### 第四層：擴容與跨鏈

這一層解決的是可擴充套件性問題——如何讓鏈處理更多交易、更低成本：

| 術語 | 縮寫 | 中文 | 說明 |
|-----|------|------|------|
| Layer 1 | L1 | 第一層（主鏈） | 比特幣、以太坊這類基礎區塊鏈 |
| Layer 2 | L2 | 第二層 | 建立在 L1 之上、繼承 L1 安全性的擴容方案 |
| Rollup | - | 彙總 | 將多筆交易打包後提交到 L1 的擴容方式 |
| Optimistic Rollup | - | 樂觀彙總 | 預設交易有效，有問題才觸發欺詐證明；代表：Arbitrum、Optimism |
| ZK Rollup | - | 零知識彙總 | 用零知識證明即時證明交易有效；代表：zkSync、Starknet |
| Bridge | - | 跨鏈橋 | 連線兩條不同區塊鏈的協議，可互轉資產 |
| TVL | Total Value Locked | 鎖定總價值 | 某個協議中使用者存入的資產總額 |
| Blob | - | 資料塊 | 以太坊 EIP-4844(2024 年 Dencun 升級)引入的廉價資料儲存方式 |
| Sidechain | - | 側鏈 | 與主鏈並行執行、通過橋接互動資產的獨立鏈 |
| Sharding | - | 分片 | 把網路拆成多個並行處理片區以提升整體吞吐量 |
| Data Availability | DA | 資料可用性 | 保證交易資料確實被公開發布、可供任何人驗證 |
| Finality | - | 最終性 | 交易被網路確認後不可逆轉的狀態 |
| Interoperability | - | 互操作性 | 不同區塊鏈之間傳遞資產和資訊的能力 |
| Cross-chain | - | 跨鏈 | 泛指資產或訊息在不同區塊鏈間流轉的行為 |

## 🧪 真實場景：在 Arbitrum 上交換代幣

你在 Arbitrum(L2)通過 Uniswap 用 1000 USDC 換 ETH，過程分兩步：

**第一步：授權(Approval)** — 呼叫 USDC 代幣合約的 approve 函式，Gas fee 約 2 美元

**第二步：交換(Swap)** — Uniswap 合約從流動性池提取 ETH 給你，Gas fee 約 0.5 美元（L2 便宜 100-1000 倍）

交易完成後得到一個 Tx Hash，在 Arbiscan 查詢。7 天內沒被欺詐證明挑戰，就在 L1 最終確認。這個過程涉及：L2、Approval、Swap、Gas、Tx Hash、AMM、流動性……都是上面表格裡的術語。

## ⚠️ 常見坑與誤區

1. **Gas 和 Gwei 混淆**
   - 費用 = Gas 用量 × Gas 價格(Gwei)，轉換回 ETH 需除以 10^9

2. **地址和私鑰混淆**
   - 地址公開如銀行卡號，私鑰絕密如密碼，永遠不要分享私鑰

3. **「授權」與「轉帳」混淆**
   - 授權(Approve)只給許可權不轉帳，實際轉帳需第二筆交易

4. **跨鏈地址混淆**
   - Bitcoin 和 Ethereum 地址格式完全不同，轉錯無法恢復

## 本節要點

- Web3 術語按層級分為：基礎單位 → 網路參與者 → 智能合約 → 擴容
- Gas 費 = Gas 用量 × Gas 價格(Gwei)，轉換回 ETH 需除以 10^9
- 地址公開如帳號，私鑰絕密如密碼，永不混淆亦不外洩
- Layer 2 通過 Rollup 繼承 L1 安全性，交易成本降低 100-1000 倍
- 「授權(Approve)」只給許可權不轉帳，實際轉帳需第二筆交易
