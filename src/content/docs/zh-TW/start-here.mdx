## 先說清楚：這本書想幫你做到什麼

讀完之後，你應該能做到下面五件事中的任意一件——而不是「聽說過很多名詞」：

1. 向一個完全不懂的人，用三分鐘講清楚區塊鏈為什麼改不了；
2. 獨立建立並安全管理一個自託管錢包，看懂每一筆交易的每一欄；
3. 開啟一個陌生專案的合約地址，判斷它有沒有明顯的跑路準備；
4. 用一套固定流程，產出一份結構完整的專案研究報告；
5. 看懂 Web3 行業的崗位地圖，知道自己缺哪塊能力、怎麼補。

<Aside type="caution" title="不會幫你做到的事">
本書**不推薦任何具體幣種、協議或平臺去投資**，不預測價格，也不提供「穩賺方法」。文中出現的所有專案都只作為機制講解的例子。
</Aside>

## 閱讀約定

<Steps>

1. **每節開頭有「一句話結論」**：趕時間的話，只讀這一行 + 末尾的「本節要點」，也能建立骨架。

2. **帶 🧪 的段落是可跟做的實操**：需要你開啟瀏覽器或錢包。第一次做建議用**測試網**或**極小金額**。

3. **帶 ⚠️ 的段落是真金白銀的坑**：這些通常來自真實事故，請不要跳過。

4. **術語首次出現時給中英文對照**：例如「無常損失（Impermanent Loss，IL）」。全書術語彙總見[第 1 章第 3 節](/zh-TW/01-what-is-web3/03-glossary-map/)。

5. **所有數字都標註了口徑與時間**：加密行業變化極快，看到具體數值時請注意它的時間戳，並自行核實最新情況。

</Steps>
