| 閃電貸攻擊 | Flash Loan Attack | 借來無抵押鉅款，在一筆交易內操縱價格榨乾協議再還款走人 | [8.7](/zh-TW/08-defi/07-defi-risks/) |

## 最容易混淆的 8 組概念

| 概念 A | 概念 B | 核心區別 |
|---|---|---|
| Layer 1（[2.6](/zh-TW/02-blockchain-basics/06-trilemma/)） | Layer 2（[9.1](/zh-TW/09-layer2-multichain/01-why-scaling/)） | L1 是獨立結算的基礎鏈，安全和最終性都由自己承擔；L2 建在 L1 之上處理交易，定期向 L1 提交證明，安全性來自 L1 |
| APR（[8.3](/zh-TW/08-defi/03-yield-farming/)） | APY（[8.3](/zh-TW/08-defi/03-yield-farming/)） | APR 是不計複利的年化數字，看著更高；APY 計入復投頻率，才是更貼近真實到手收益的口徑 |
| 代幣（[6.1](/zh-TW/06-tokens-nft/01-token-standards/)） | 幣（原生代幣 / Coin） | 幣指某條鏈自己的原生資產（如 ETH、BTC），用來付 Gas；代幣是在別人的鏈上用合約標準發行的資產，本身不能直接付 Gas |
| 熱錢包（[4.1](/zh-TW/04-wallets/01-wallet-types/)） | 冷錢包（[4.1](/zh-TW/04-wallets/01-wallet-types/)） | 熱錢包私鑰在聯網裝置上，操作快但暴露面大；冷錢包私鑰從不接觸網路，安全性高但每次交易流程更繁瑣 |
| 無常損失（[7.4](/zh-TW/07-exchanges-trading/04-lp-and-il/)） | 普通虧損 | 無常損失特指做市商因池內兩種資產價格比例變動、相對單純持有產生的帳面差額，撤出後才會"坐實"；普通虧損是資產本身價格下跌造成的直接損失 |
| 私鑰（[3.2](/zh-TW/03-cryptography/02-private-public-key/)） | 助記詞（[3.3](/zh-TW/03-cryptography/03-mnemonic-bip39/)） | 私鑰對應單個地址，是最終的簽名金鑰；助記詞是一整個種子，能通過 HD 派生生成無數個私鑰和地址 |
| Rollup（[9.2](/zh-TW/09-layer2-multichain/02-rollup-optimistic/)） | 側鏈（[9.4](/zh-TW/09-layer2-multichain/04-l2-landscape/)） | Rollup 把交易資料和證明提交回 L1，安全性繼承主鏈；側鏈是獨立執行的另一條鏈，靠自己的驗證者集合保障安全，風險與主鏈無關 |
| 質押（[2.5](/zh-TW/02-blockchain-basics/05-consensus-pos/)） | 挖礦（[2.4](/zh-TW/02-blockchain-basics/04-consensus-pow/)） | 質押是 PoS 機制下鎖定資本參與共識，作惡被扣本金；挖礦是 PoW 機制下用算力競爭記帳權，成本是電力和硬體而非資本凍結 |
