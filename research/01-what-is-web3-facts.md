## 按小节整理的事实要点

### 小节1：Web1 / Web2 / Web3：三代互联网的所有权之争

#### Web代际的本质区别
| 代际 | 特性 | 数据所有权 | 应用形式 |
|-----|------|---------|--------|
| **Web1** | 静态内容、只读体验、最小用户交互 | 中心化服务商 | 纯信息展示 |
| **Web2** | 动态页面、用户生成内容(UGC)、社交网络 | 中心化公司垄断 | 社交平台集中流量 |
| **Web3** | 区块链基础、去中心化应用(DApp)、智能合约 | **用户自主控制** | 点对点价值传递 |

#### Web3的核心技术基础（四大支柱）
1. **区块链**：分布式账本，每个节点保存完整副本，交易由多节点共识验证
2. **智能合约**：自执行协议，确保交易可靠执行
3. **加密货币**：支付与网络参与的数字资产
4. **去中心化应用(DApp)**：独立于中心化服务器运行

#### Web3 vs Web2的五大区别
- **去中心化**：无单一控制权
- **隐私保护**：用户拥有数据所有权
- **透明性**：所有交易公开可验证
- **审查抵抗**：分布式结构无法强制内容移除
- **社区治理**：通过投票机制进行决策

### 小节2：为什么要去中心化？中心化平台真正的三个痛点

#### Web2中心化的三大痛点（当前实证）
1. **用户数据垄断**：Web2.0时代大公司垄断用户生成的数据，用户失去对自身数据的主权
2. **创作者依赖**：创作者无法直接与用户交互，必须通过第三方平台中介
3. **审查与隐私威胁**：中心化平台拥有绝对的内容审查权，用户隐私处于风险中

#### Web3去中心化的对标优势
- 用户数据由用户主宰，而非平台垄断
- 创作者可直接展示作品，无需第三方干预
- 分布式存储使数据不存储在单一服务器，而是分散在多个节点中

### 小节3：术语速通地图：60个高频词

#### 区块链基础术语（必须正确使用）
- **Wei**：ETH最小单位（1 ETH = 10^18 Wei）
- **Gwei**：Gas计价单位（1 Gwei = 10^9 Wei）
- **Gas**：以太坊交易消耗的计算资源单位，价格以Gwei表示
- **交易费用计算**：Gas用量 × Gas价格(Gwei)
- **共识机制**：PoW(工作量证明)、PoS(权益证明)
- **EIP**：以太坊改进提案(Ethereum Improvement Proposal)

#### 网络参与者术语
- **验证者(Validator)**：PoS网络中参与共识的节点运营者
- **验证者最小质押**：32 ETH（当前标准）
- **验证者最大有效余额(MaxEB)**：2,048 ETH（EIP-7251升级后）
- **节点**：运行区块链软件的计算机

#### Layer 2与扩容术语
- **Optimistic Rollup**：乐观汇总（Arbitrum、Optimism、Base）
- **ZK Rollup**：零知识汇总（zkSync、Starknet）
- **TVL(Total Value Locked)**：协议中锁定的总价值

### 小节4：「价值互联网」：当信息可以复制，而钱不能

#### Web3作为价值互联网的根本差异
- **Web1/Web2**：信息互联网，侧重数据/信息消费，信息可无限复制
- **Web3**：价值互联网，面向所有用户创造财富，**钱和资产不能任意复制**
  - 每个代币/NFT的唯一性通过区块链的密码学保证
  - 双花问题通过共识机制解决（PoW/PoS）
  - 所有权转移通过不可篡改的交易记录验证

#### 密码学确保性
- 私钥所有权 = 资产完全控制权
- 公钥地址作为身份标识
- 签名机制保证交易真实性

### 小节5：Web3技术栈全景图：从底层链到应用层

#### 完整技术栈五层模型

**第5层：用户界面与钱包**

### 小节7：破除幻觉：Web3被吹过头的部分与被低估的部分

#### 被吹过头的说法（需要纠正）
1. **"Web3会完全替代中心化服务"** → 现实：混合模式共存，中心化服务仍是主流
2. **"所有数据都在链上"** → 现实：成本限制，大多数数据在链下存储(IPFS/Arweave)，链上仅保留哈希指针
3. **"Web3零成本交易"** → 现实：Layer 1(以太坊)Gas费仍需支付，L2虽然便宜但非零(平均几美分到几美元)
4. **"完全匿名隐私"** → 现实：地址匿名但交易记录永久公开，链上分析公司可追踪资金流

#### 被低估的部分
1. **可编程资产**：智能合约能创造过去中心化系统无法实现的动态金融产品
2. **全球结算**：24/7无假期清算，优于传统金融的T+2结算
3. **代码即法律**：自执行合约消除交易对手方风险
4. **资本效率提升**：DeFi原语可复合(如Lego blocks)，以太坊质押年化收益稳定在3-4%

## 事实核查方法论说明

### 本报告的数据来源分类

1. **协议层参数**(不变)：区块时间、最小质押、单位换算 → 来自官方文档
2. **实时生态数据**(易变)：TVL、交易量、市场份额 → 来自主流数据聚合商(The Block、DEXTools)，注明采样时间
3. **升级计划**(可能延期)：Glamsterdam、Hegotá → 来自EF官方路线图，标注"计划"
4. **已发生事件**(不变)：时间线、主网升级 → 来自官方区块浏览器和新闻记录
5. **产品现状**(年度变化)：钱包功能、链支持数 → 来自官方2026年公告

### 本章高风险概念预警

⚠️ 这些概念容易被误解或过度宣传，撰文时需谨慎：
- **去中心化程度**：实际中大多数L2仍依赖多签验证者集团
- **隐私强度**：链上交易永久公开，零知识证明是可选隐私层
- **能耗问题**：PoS确实低能耗，但不会完全消除共识成本
- **交易最终性**：L1需12分钟确认，L2需更多块确认，远非"即时"
